# MöbelPlan Web MVP

Xcode 없이 Visual Studio Code와 브라우저만으로 실행되는 로컬 웹/PWA 버전입니다. 외부 패키지, 서버, API 키, 계정이 필요하지 않습니다.

## Visual Studio Code에서 실행

1. Visual Studio Code에서 이 폴더를 엽니다.
2. 상단 메뉴에서 **Terminal → Run Build Task…**를 선택합니다.
3. **MöbelPlan starten**을 선택합니다.
4. 브라우저에서 [http://127.0.0.1:4173](http://127.0.0.1:4173)을 엽니다.

또는 VS Code 터미널에서 다음 명령 하나만 실행할 수 있습니다.

```bash
npm start
```

종료하려면 실행 중인 터미널에서 `Control + C`를 누릅니다.

## 구현된 흐름

- Home 검색, 7개 카테고리, Neue Wohnung 진입점
- 공식 판매처 가격과 배송비 상태를 분리한 검색 결과
- 판매처 로고형 워드마크와 28개 실제 상품의 공식 상세 페이지 링크
- 저작권이 불명확한 상품 이미지를 사용하지 않는 출처 확인형 카드
- 별도 Filter 시트
- 상품 상세와 접이식 정보
- 최대 3개 상품 비교
- 여러 판매처를 담는 Universal Warenkorb
- 장바구니 상품별 수량 조절과 수량 기반 실시간 합계 계산
- PLZ, 층수, 엘리베이터, 날짜 기반 배송 견적
- 확인 가능한 경우에만 표시하는 배송 포함 총액과 예상 절약액
- 다중 판매처 배송 Tracking 데모
- 브라우저 로컬 저장으로 장바구니와 비교 목록 유지
- 모바일과 데스크톱 반응형 UI

## 데이터 기준과 Mock 범위

- 28개 상품명, 가격, 치수, 소재, 색상, 재고 문구는 각 공식 상품 페이지를 기준으로 2026-09-28에 다시 확인한 로컬 스냅샷입니다.
- 배송비가 우편번호·옵션·로그인 상태에 따라 달라지는 상품은 임의의 숫자를 넣지 않고 `Im Shop prüfen`으로 표시합니다.
- 배송비가 공식 상품 페이지에 명시된 경우에만 `Gesamt mit Händler-Versand`를 확정 숫자로 보여줍니다.
- `MVP-Sammellieferung` 비용은 실제 판매처 데이터가 아니라 이 프로토타입의 로컬 견적 공식입니다.
- 가격·재고·프로모션은 수시로 바뀔 수 있으므로 구매 전 카드의 공식 상세 페이지 링크에서 최종 확인해야 합니다.

실제 주문, 결제, 로그인, 판매처 API, 웹 스크래핑, 실시간 위치 추적은 포함하지 않습니다.
