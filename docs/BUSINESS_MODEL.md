# MöbelPlan 수익모델

데이터 기준: 2026-09-28  
초기 시장: Berlin 1개 권역, 22–29세 Berufseinsteiger, 첫 집을 위해 2–5개 가구를 구매하는 사용자

## 한 문장 모델

여러 판매처의 가구를 한 번에 수령하고 싶은 고객에게 **투명한 Sammellieferung 고정 견적**을 판매하고, 검증 이후 운송 파트너 수수료와 부가 서비스로 수익원을 확장한다.

## 우선순위

### 1. Sammellieferung 마진 — 지금 검증할 핵심 수익

고객 결제액에서 실제 운송 파트너 비용, 결제 수수료, 파손·고객지원 충당금을 뺀 금액이 공헌이익이다.

MVP 견적 공식:

- 기본 €89: 판매처 1곳, 상품 1개
- 추가 판매처: 곳당 €18
- 추가 상품: 개당 €8
- 엘리베이터가 없을 때: 층당 €12
- 토요일 배송: €19

예시: 판매처 2곳, 상품 3개, 엘리베이터 있음, 토요일 배송은 `€89 + €18 + €16 + €19 = €142`다.

이 가격은 확정 상용요금이 아니라 첫 10건의 원가를 측정하기 위한 시작점이다. 베를린 공개 가격표에서는 소형 차량 운송이 약 €70부터, 평균 운송비가 약 €120이며, 차량 크기·거리·층수·인력에 따라 올라간다. 따라서 기존 €49 기본가는 적자 위험이 높다.

### 2. 부가 서비스 — 첫 매출 이후

- Wohnung까지 운반: 2인 운반 필요 시 별도 견적
- Möbelmontage: 품목별 또는 시간당 요금
- Alt-Möbel Entsorgung: 건별 요금
- Wunschzeitfenster: 좁은 배송 시간대 프리미엄
- Express-Abholung: 24–48시간 내 픽업 프리미엄

### 3. Händler/운송 파트너 매출 — 주문량이 생긴 뒤

- 운송 파트너에게 검증된 배송 리드 제공 후 건당 중개 수수료
- 판매처 제휴 링크 또는 판매 성과 수수료
- 판매처용 우선 노출은 반드시 `Gesponsert`로 명확히 표시

초기에는 제휴수수료를 사업성의 전제로 두지 않는다. 고객이 배송비를 지불해도 성립하는지를 먼저 확인한다.

### 지금 하지 않을 모델

- 소비자 월 구독: 이사는 반복 빈도가 낮아 초기 타겟과 맞지 않음
- 상품 가격에 숨겨진 마진: Händler-Transparenz 원칙과 충돌
- 전국 자체 차량망: €1,000 예산으로 불가능
- 광고 배너: 초기 신뢰와 정보 계층을 훼손

## 건당 손익 기준

첫 10건마다 아래 숫자를 기록한다.

| 항목 | 목표 |
|---|---:|
| 고객 결제액 | 견적별 기록 |
| 운송 파트너 지급액 | 견적의 60–70% 이하 |
| 결제·고객지원·파손 충당 | 5–10% |
| 건당 공헌이익 | 최소 €25 |
| 공헌이익률 | 최소 20% |
| 취소/재배송 | 10% 미만 |

`공헌이익 = 고객 결제액 − 운송원가 − 결제비용 − 파손/지원 충당금`

공헌이익이 €25 미만인 조건은 자동화하기 전에 가격을 올리거나 서비스 범위에서 제외한다.

## €1,000 사용안

| 용도 | 금액 |
|---|---:|
| 실제 배송 테스트 3–5건의 손실 한도 | €450 |
| Berlin 타겟 광고/랜딩 테스트 | €200 |
| 도메인·이메일·기초 운영 | €80 |
| 약관·운송책임·보험 상담 준비금 | €170 |
| 예비비 | €100 |

개발 외주와 전국 광고에는 사용하지 않는다.

## 4주 검증 순서

1. 1주차: Berlin 한 권역에서 견적 요청 20건 확보
2. 2주차: 유료 예약 3건 목표, 고객이 거절한 가격과 이유 기록
3. 3주차: 실제 운송 3건 실행, 픽업 대기·주행·운반 시간을 분 단위로 기록
4. 4주차: 공헌이익이 양수인 주문 유형만 남기고 가격식 조정

중단 기준: 30개의 유효 견적 중 유료 전환이 3건 미만이거나, 5건 연속 공헌이익이 음수이면 기능 개발보다 가격·운영 모델을 먼저 재설계한다.
